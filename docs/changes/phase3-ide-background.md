# PH3-IDE-11：后台运行（切标签时任务仍在推进）

- 日期：2026-09-26
- 改动：`verify-agent-timeline.js` 的 ⑥ 节**重写**
- 验证：`verify-agent-timeline` 22 → **33/0**

## 原来的 ⑥ 节等于没验

它只断言了 `typeof active === 'boolean'` —— **恒真**，所以"切标签后任务还在"这句话
当时**没有**得到任何验证。清单要的是"切走之后 Agent 任务**继续**"，
"快照还在"与"仍在推进"是两件事。

## 重写后验三件事

1. **切走后 `active` 仍是 `true`**（任务没被中断），且**切标签本身不产生步骤**；
2. **在别的标签页上调 `step` 真的进去了** —— 这是"仍在推进"的**实证**；
   失败那一步也**如实记录**（后台不美化）；
3. **切回来能接上**：步数**继续累加、没重置**，前后的步骤都在，`goal` 也没被改掉。
   最后收尾时 `active` 变 `false`，全程步数一次没丢。

## 两处自己的错（都是当场被工具抓到的）

- **`chk` 传了字符串** —— type gate（`verify-harness`）**当场 FAIL** 并提示"用 `eq`"。
  这正是当初加这个 gate 的理由：它专治 `chk`/`eq` 混用。
- **步数数错了**：`begin()` **不产生**步骤，所以是 2（后台）+ 1（回来）+ 1（收尾）= 4，
  我写成了 `>= 5`。
