- 日期：2026-09-25

- 状态：**DONE**；`verify-session-memory-ui` **17/0**

此前 P10（会话）与 P11（项目记忆）都只做到了"数据层 + IPC + 存储"，
界面这两个面板一直缺着 —— 也就是说**能力在、但看不见**。

## P10 会话面板

显示**绑定当前项目**的那条会话：id / 绑定项目 / 状态，以及四类记录的计数与明细
（消息、工具调用、补丁、验证）。**不给"改历史"的入口** —— 历史是事实。

端到端验的是"它真的跟着项目走"：打开 A 追加一句话 → 切到 B，**会话 id 变了、且看不到 A 那句话**。

另外：**未打开项目时面板不崩**，给的是"先打开一个项目"这类可读说明
（而不是空白或异常）。

## P11 项目知识面板

规则列表（`!` 开头标出**硬约束**）+ 已验证经验；还有一个「创建/刷新」按钮
（调 `memoryEnsure`，也就是把 `.moonbit-work/` 补齐）。

**最要紧的一条：面板上不提供"编辑规则"** —— P11-05 说规则不可无确认修改，
它是"约束 Agent 自己"的东西。端到端直接把这条断言了：

```
记忆面板只有 创建/刷新 与 关闭  →  eq(btns, ['创建/刷新', '关闭'])
```
